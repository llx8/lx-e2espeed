# RTX 5090

Facts that change optimization decisions. Checked 2026-09-23; confirm on the machine with the commands below.

## Key numbers
- Architecture: Blackwell (GB202), compute capability 12.0 (sm_120).
- 170 SMs; 32 GB GDDR7 on a 512-bit bus, about 1.8 TB/s.
- L2 cache: about 96 MB.
- Host link: PCIe 5.0 x16. No NVLink, so multi-GPU traffic goes over PCIe.
- Board power limit: 575 W by default.

## What follows from them
- sm_120 is not sm_100. Kernels written for datacenter Blackwell (tcgen05, tensor memory) or for Hopper (sm_90a, wgmma) do not run here. Libraries fall back to other paths, sometimes slower ones, so profile to see which kernels actually run.
- Software needs sm_120 support: CUDA 12.8 or newer and a framework build that includes it. Check with `torch.cuda.get_arch_list()`.
- Tensor cores support FP8 and FP4, but switching precision changes numerics, so it needs the user's approval like any precision change.
- 32 GB bounds batch size and model size.
- PCIe is far slower than device memory, so avoid host-device round trips on the hot path.
- Clocks vary with temperature and power; see `rules/benchmarking.md`.

## Query on the machine
    nvidia-smi --query-gpu=name,driver_version,memory.total,power.limit,clocks.max.sm,compute_cap,pcie.link.gen.max --format=csv
    nvidia-smi -q -d PERFORMANCE
    python3 -c "import torch; print(torch.__version__, torch.version.cuda, torch.cuda.get_arch_list())"
