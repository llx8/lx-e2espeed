# Night trials

One row per trial of a night run (rules/night.md). `lx-e2espeed/exp.sh try` adds each row as running; park, drop, and adopt set the status. Fill in the main scenario's A/B against the trial's base, the difference level, and what the user must decide; NOTE.md has every scenario.
Trials start from the same base and do not build on each other, so their gains do not add up.

## Queue
Methods not tried yet, most promising first, each with its evidence; a blocked one says what it needs (a dependency, a user decision).
